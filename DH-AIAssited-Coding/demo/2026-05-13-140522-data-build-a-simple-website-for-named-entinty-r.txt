❯ The results are iffy, are there any better techniques for ner that we could   
  use?                                                                          

● Good question. The gazetteer is limited because it can only highlight names
  that the editors already mentioned in metadata — it misses "Xenophon",
  "Alexander", "Ld Clive", "Sir W. Wiseman" when not foot-noted, and
  over-matches common surnames. Better options, roughly worst→best for this
  corpus:

  1. In-browser transformer NER (transformers.js + a model like 
  Xenova/bert-base-NER) — proper ML, runs offline after a ~50 MB download. But
  these models are trained on modern news text and stumble on 19thC prose:
  archaic titles ("Ld", "Dr"), continental names, ship names, species names.
  2. GLiNER zero-shot NER in browser — small model (~150 MB), lets you define
  entity types ("historical figure", "ship", "species", "publication"). Better
  fit for a TEI corpus, still browser-only.
  3. Pre-process once with the Claude API, cache to JSON (recommended) — run
  each XML through Claude with a prompt that knows the domain ("19thC scientific
   correspondence; tag persons including titled forms like 'Ld Clive', places,
